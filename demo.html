Test document: edit me freely

A sample file for trying out Pree HTML Station. Click any text to edit (in Edit mode), then Cmd+S to save back to this file.

The gist

Click on this line — the caret lands where you clicked. Then just type, like editing a Word document.

Select text and use the toolbar: bold, italic, underline, strikethrough, or font colors.
